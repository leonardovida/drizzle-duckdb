# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub security advisories:
open the [Security tab](https://github.com/leonardovida/drizzle-duckdb/security)
of this repository and choose **Report a vulnerability**.

Include the affected package version, the `@duckdb/node-api` and `drizzle-orm`
versions, and steps or code that reproduce the issue. We will confirm receipt,
investigate, and share a fix or mitigation plan through the advisory.

## Supported versions

Security fixes land on the latest release of `@duckdbfan/drizzle-duckdb`.
Upgrade to the newest version before reporting when you can.
